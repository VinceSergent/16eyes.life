# 16eyes.life

Site for 16eyes. Next.js, hosted on Vercel.

- `public/landing.html`: the landing page (served at `/`). Self-contained WebGL page; Three.js r128 is vendored in `public/vendor/`.
- `app/`: room for the rest of the site (shop, "go deeper" experience).

Run locally: `npm install && npm run dev`, then open http://localhost:3000.
